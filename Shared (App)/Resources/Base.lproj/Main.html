Redirect

Create exact URL-to-URL redirects from the Safari toolbar. Redirect runs on normal websites and needs website access for the pages you want to match.

Turn on Redirect in Settings, then allow website access for the sites you want to redirect.

Turn on Redirect in Safari Extensions settings, then allow website access for the sites you want to redirect.

Redirect is on. Manage website access in Safari if a rule is not triggering.

Redirect is off. Turn it on in Safari Extensions settings before your rules can run.

Safari profiles and private browsing can require separate extension approval.
