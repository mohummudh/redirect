Safari Access

Redirect requests access to all normal websites because your rules are user-defined. Safari can still ask you to allow access for specific sites, profiles, or private browsing.

  • Enable the extension in each Safari profile where you want redirects to work.
  • Allow website access for the sites you want to redirect from.
  • Private Browsing may require separate approval before Redirect can run.
